SPEEDSIGNAL — INTERNET SPEED GUIDES
WordPress Theme v1.0.0

WHAT THIS THEME DOES
- Provides a responsive, custom-designed website with a dark editorial hero, metric cards, troubleshooting paths, FAQ section, app promotion sections, article listings and mobile navigation.
- On theme activation, creates starter pages and evergreen guides if a page/post with the same slug does not already exist.
- Sets the new Home page as the static front page and the Guides page as the posts page.
- Creates Primary and Footer navigation menus.
- Adds page descriptions, Open Graph tags and basic WebSite, Organization, SoftwareApplication and BlogPosting structured data unless a detected SEO plugin is already managing these outputs.
- Links to PingMaster Pro: Speed Test on Google Play in the navigation, homepage, guide pages, article templates and footer. Standard editorial links are used; no rel="nofollow" is added.
- Includes a shortcode: [pingmaster_app_button label="Get PingMaster Pro"]

IMPORTANT NOTES
- The hero dashboard is a visual illustration only. It does not claim to run a live browser-based speed test. The site promotes the Android app and explains how to interpret network measurements.
- Theme activation publishes starter pages and posts into the WordPress database. Deactivating the theme does not delete that content. Existing pages/posts with matching slugs are reused rather than overwritten.
- The Privacy and Site Notes page is a starter text, not legal advice. Review it against your actual analytics, cookies, forms, WordPress.com settings and applicable requirements before relying on it as a legal policy.
- SEO markup and crawlable links cannot guarantee rankings, indexing or backlink value. Search engines decide how links and pages are evaluated. Review the content and add first-hand evidence, screenshots, editorial improvements and useful sources where appropriate.
- If you already use Yoast SEO, Rank Math, AIOSEO or SEOPress, the theme avoids outputting its own meta/schema block to reduce duplication. Confirm the active SEO plugin is configured correctly after activation.
- The theme is designed for WordPress.com sites where custom theme upload is enabled, and for self-hosted WordPress installations. WordPress.com Free plans do not support custom theme uploads; an eligible paid plan is required.

INSTALLATION
1. Keep this ZIP compressed.
2. In WordPress, open Appearance → Themes → Add New → Upload Theme.
3. Choose the ZIP file, click Install Now, then Activate.
4. Visit the homepage and check Home, Guides, the main menu, footer, article cards and app links on desktop and mobile.
5. Review Pages → Privacy and Site Notes and edit it to match the site's real setup.
6. In Settings → Reading, confirm the static Home page and Guides posts page if you need to adjust them.
7. If your site has an SEO plugin, open its settings and set the desired site title, meta descriptions and sitemap controls there.
